# Principais comandos do Nestjs

1.  npx nest --help

2.  npx nest --version

3.  npx nest g mo user (comando com nest cli para criar o module users)

4.  npx nest g co user --no-spec (comando com nest cli para criar o controler)

5.  npx nest g s user --no-spec (comando com nest cli para criar o service)

6.  npx nest g cl user/entities/user.entity --no-spec --flat (comando para criar
    a classe de entidade que representa o meu usuário no banco de dados)

7.  npx nest g cl user/dto/create.user.dto --no-spec --flat (comando para criar
    a classe de DTO para criação de novo usuário)

8.  npx nest g res post (comando para gerar todos os recursos para o module
    post)

9.  npm i @nestjs/typeorm typeorm better-sqlite3 (comando para instalar a ORM no
    nestJS e o driver do banco de dados sqlite3)

10. npm i @nestjs/jwt (Instalação do pacote oficial do Jwt no nestjs)
